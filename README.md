# Curso PRL · Personal de cátering

Curso PRL art. 19 Ley 31/1995 para el puesto de personal de cátering (Previjob). Contenido genérico, válido para cualquier empresa.

- Web: https://curso-prl-catering.onrender.com
- Panel único de administración: https://curso-prl-taf-api.onrender.com/admin/?curso=cat
- API compartida: curso-prl-taf-api (código de curso `cat`, PRL-CAT)

Estructura: `src/m*.js` (contenido), `src/engine.js`, `src/template.html`. Generar con `cd src && python3 build.py` → `index.html`, `admin/index.html`, `course-meta.json`.
